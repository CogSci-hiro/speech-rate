rate Documentation
==================

``rate`` provides scaffolding utilities for speech-rate analysis workflows, including
configuration validation, dataset indexing, canonical events-table generation, and
run-manifest creation. The documentation below covers installation, the public Python
API, and executable examples built with Sphinx Gallery.
